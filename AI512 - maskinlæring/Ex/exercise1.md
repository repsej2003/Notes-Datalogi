## Question 1

Let $\mathcal{X}=\{1,2,3\}$, $\mathcal{Y}=\{0,1\}$, and let $\ell$ be the zero-one loss. Let $\mathcal{D}$ be a distribution over $\mathcal{X}\times\mathcal{Y}$ whose marginal $\mathcal{D}_{\mathcal{X}}$ is uniform on $\mathcal{X}$ and whose labels are deterministic, $y=f(x)$, for a fixed, unknown labeling function $f:\mathcal{X}\to\{0,1\}$. Write $q:=P_{x\sim\mathcal{D}_{\mathcal{X}}}\big(f(x)=1\big)$ and let $\mathcal{H}_{\mathrm{all}}:=\mathcal{Y}^{\mathcal{X}}$ collect **all** hypotheses $h:\mathcal{X}\to\mathcal{Y}$. Let $S=\{(x_i,y_i)\}_{i=1}^m \overset{\text{i.i.d.}}{\sim}\mathcal{D}$ with $m\ge1$.

Evaluate the following statements.

**Answer 1.1:** $|\mathcal{H}_{\mathrm{all}}|=8$; more generally, for finite $\mathcal{X}$ and $\mathcal{Y}$, the number of distinct hypotheses $h:\mathcal{X}\to\mathcal{Y}$ is $|\mathcal{Y}|^{|\mathcal{X}|}$.

**Answer 1.2:** If a data set of input–label pairs were to contain two points $(x,0)$ and $(x,1)$ sharing the same input $x$, it could not have been generated by the model above.

**Answer 1.3:** If $h,h'\in\mathcal{Y}^{\mathcal{X}}$ agree on at least two of the three inputs, then $|R(h)-R(h')|\le\frac13$.

**Answer 1.4:** For a fixed hypothesis $h$, the true risk $R(h)$ is a function of the random sample $S$, hence a random variable; this is why it must be estimated from data.

**Answer 1.5:** If $f\in\mathcal{H}$ — for instance, $\mathcal{H}=\mathcal{H}_{\mathrm{all}}$ — then for every $S$, every $h_S\in\arg\min_{h\in\mathcal{H}}\widehat R_S(h)$ satisfies $R(h_S)=0$.

## Question 2

Let $\mathcal{X}=[0,1]$ with $\mathcal{D}_{\mathcal{X}}$ uniform, $\mathcal{Y}=\{0,1\}$, and the zero-one loss, with $y=f(x)$ for an unknown $f:\mathcal{X}\to\{0,1\}$ satisfying $q:=P(f(x)=1)\in(0,1)$ (both label values occur on sets of positive probability). Consider the hypothesis class $\mathcal{H}:=\{h_0,h_1\}$ containing only the two constants $h_0\equiv0$ and $h_1\equiv1$.

Evaluate the following statements. All probabilistic claims are over the draw of $S\sim\mathcal{D}^m$.

**Answer 2.1:** For every $S$: $\ \widehat R_S(h_0)+\widehat R_S(h_1)=1$; and for every admissible $f$: $\ R(h_0)+R(h_1)=1$.

**Answer 2.2:** If the zero-one loss is replaced by the squared loss $\ell(y,y')=(y-y')^2$, the set of ERM solutions over $\mathcal{H}$ is unchanged, for every $S$.

**Answer 2.3:** If both $h_0$ and $h_1$ minimize $\widehat R_S$ over $\mathcal{H}$, then $R(h_0)=R(h_1)$.

**Answer 2.4:** For every $S$: $\ \min_{h\in\mathcal{H}}\widehat R_S(h)$ equals the frequency of the minority label in $S$; and for every admissible $f$: $\ \min_{h\in\mathcal{H}}R(h)=\min(q,1-q)\le\frac12$ — the best hypothesis in the class is the constant majority vote.

**Answer 2.5:** For every $S$: every ERM output $h_S\in\arg\min_{h\in\mathcal{H}}\widehat R_S(h)$ satisfies $R(h_S)\le\frac12$ — empirical risk minimization over $\mathcal{H}$ never returns a hypothesis whose true risk exceeds one half.

## Question 3

Let $\mathcal{X}=[0,1]$, $\mathcal{Y}=\mathbb{R}$, and $\ell(y,y')=(y-y')^2$. The true labeling function is $f(x)=\sin(2\pi x)$ (unknown to the learner). A **training set** $S_{train}=\{(x_i,y_i)\}_{i=1}^m$ consists of $m$ distinct inputs $x_i\in[0,1]$ with labels $y_i=f(x_i)+\varepsilon_i$, where the $\varepsilon_i$ are arbitrary real numbers — a noise realization. A **test set** $S_{test}=\{(\tilde x_j,\tilde y_j)\}_{j=1}^k$ is of the same form, with inputs distinct from each other and from the training inputs. For $M\ge0$ let

$$\mathcal{H}_M:=\Big\{x\mapsto\sum_{j=0}^M w_jx^j\ :\ w\in\mathbb{R}^{M+1}\Big\}$$

(the polynomial degree $M$ is a hyperparameter) and let $h^{(M)}\in\arg\min_{h\in\mathcal{H}_M}\widehat R_{S_{train}}(h)$ be any least-squares fit. You may use the following classical fact, given without proof: for any $m$ distinct inputs $x_1,\ldots,x_m$ and any values $v_1,\ldots,v_m\in\mathbb{R}$, there exists a polynomial $p$ of degree at most $m-1$ with $p(x_i)=v_i$ for all $i\in[m]$.

Evaluate the following statements. All of them quantify over all admissible data sets (all $m,k\ge1$, all distinct inputs, all noise realizations) and all $M\ge0$.

**Answer 3.1:** $\mathcal{H}_M\subseteq\mathcal{H}_{M+1}$; consequently $\min_{h\in\mathcal{H}_{M+1}}\widehat R_{S_{train}}(h)\le\min_{h\in\mathcal{H}_M}\widehat R_{S_{train}}(h)$ — the minimum training error is non-increasing in the degree.

**Answer 3.2:** Test error is monotone in the degree: $\widehat R_{S_{test}}(h^{(M+1)})\le\widehat R_{S_{test}}(h^{(M)})$.

**Answer 3.3:** If $M\ge m-1$, then for every label vector $(y_1,\ldots,y_m)\in\mathbb{R}^m$ there exists an $h\in\mathcal{H}_M$ with $\widehat R_{S_{train}}(h)=0$; hence $\min_{h\in\mathcal{H}_M}\widehat R_{S_{train}}(h)=0$ no matter how the labels were generated — in particular when they are dominated by noise.

**Answer 3.4:** If $m\ge M+1$, then any two least-squares fits over $\mathcal{H}_M$ coincide on **all** of $\mathcal{X}$ — the fitted function is effectively unique, whatever the labels; if $m\le M$, then there are training sets and label vectors for which two distinct members of $\mathcal{H}_M$ both minimize $\widehat R_{S_{train}}$.

**Answer 3.5:** For every $B>0$: if $\widehat R_{S_{train}}(h^{(M)})\ge B$, then $\widehat R_{S_{test}}(h^{(M)})\ge B$ — a fit with high training error necessarily has high test error.

## Question 4

Let $\mathcal{X}=[0,1]$, $\mathcal{Y}=\mathbb{R}$, with labeling function $f(x)=\sin(2\pi x)$ (unknown to the learner). A **training set** $S_{train}=\{(x_i,y_i)\}_{i=1}^m$ and a **test set** $S_{test}=\{(\tilde x_j,\tilde y_j)\}_{j=1}^k$ are given, with all $m+k$ input values pairwise distinct and labels $y_i=f(x_i)+\varepsilon_i$, $\tilde y_j=f(\tilde x_j)+\tilde\varepsilon_j$ for arbitrary real noise values — no probabilistic assumption is made about them. Write $S:=S_{train}\cup S_{test}$ for the pooled data set of $n:=m+k$ points. Consider the loss functions

$$\ell_{\mathrm{sq}}(y,y'):=(y-y')^2,\qquad \ell_{\mathrm{abs}}(y,y'):=|y-y'|,\qquad \ell_{01}(y,y'):=\mathbb{1}(y\ne y'),$$

and, for a loss $\ell$, the empirical risk $\widehat R^{\ell}_{S'}(h):=\frac{1}{|S'|}\sum_{(x,y)\in S'}\ell(y,h(x))$ on a sample $S'$, as well as $\mathrm{RMSE}_{S'}(h):=\sqrt{\widehat R^{\mathrm{sq}}_{S'}(h)}$. Recall that the training error and the test error of a hypothesis $h_{S_{train}}$ learned on $S_{train}$ are $\widehat R^{\mathrm{sq}}_{S_{train}}(h_{S_{train}})$ and $\widehat R^{\mathrm{sq}}_{S_{test}}(h_{S_{train}})$: a subscript names the sample the average is taken over, and $S_{test}$ plays no role whatsoever in producing $h_{S_{train}}$.

Evaluate the following statements. They quantify over all admissible data sets, all hypothesis classes $\mathcal{H}\subseteq\mathcal{Y}^{\mathcal{X}}$, and all samples $S'$.

**Answer 4.1:** For every $S'$ and every $\mathcal{H}$: $\ \arg\min_{h\in\mathcal{H}}\mathrm{RMSE}_{S'}(h)=\arg\min_{h\in\mathcal{H}}\widehat R^{\mathrm{sq}}_{S'}(h)$ — taking the square root changes the value of the criterion but not the ranking it induces.

**Answer 4.2:** For every $S'$ and every $\mathcal{H}$: every minimizer of $\widehat R^{\mathrm{abs}}_{S'}$ over $\mathcal{H}$ also minimizes $\widehat R^{\mathrm{sq}}_{S'}$ over $\mathcal{H}$.

**Answer 4.3:** All three losses above are symmetric, $\ell(y,y')=\ell(y',y)$ for all $y,y'\in\mathbb{R}$; consequently, interchanging the two arguments of $\ell$ in the definition of $\widehat R^{\ell}_{S'}(h)$ leaves its value unchanged, for every $h$ and every $S'$.

**Answer 4.4:** For every $h$: $\ \widehat R^{\mathrm{sq}}_{S}(h)=\frac{m}{m+k}\,\widehat R^{\mathrm{sq}}_{S_{train}}(h)+\frac{k}{m+k}\,\widehat R^{\mathrm{sq}}_{S_{test}}(h)$.

**Answer 4.5:** If some $h\in\mathcal{H}$ satisfies $\widehat R^{\mathrm{sq}}_{S_{train}}(h)=0$ and some $h'\in\mathcal{H}$ satisfies $\widehat R^{\mathrm{sq}}_{S_{test}}(h')=0$, then some $\bar h\in\mathcal{H}$ satisfies both equalities simultaneously.
