
# Def linear equation
$n$ variables $x_{1},x_{2}\dots x_{n}$ is an equautin  writen on this form
$$
a_{1}x_{1}+a_{2}x_{2}+\dots + a_{n}x_{n}=b
$$
where $a_{1},\dots,a_{n},b$ are constens called coefficiets of the linear eqation
